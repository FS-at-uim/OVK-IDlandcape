📖 Anleitung zur Datenpflege (Core & Data Partner)

Diese Anleitung beschreibt die Pflege von Data Partnern, DSPs, SSPs, ID-Systemen und Usecases.

Führende Datenquelle: Nach der Anmeldung lädt der Editor direkt den aktuellen Stand aus dem offiziellen BVDW-org Repository.

A. Für Data Partner

  1. Profil aufrufen: Melde dich mit deinem persönlichen Data-Partner-Passwort an. Der Editor öffnet direkt dein Profil.
  2. Basisdaten: Name und Kurzbeschreibung deiner Datensegmente prüfen/anpassen.
  3. Unterstützte ID-Systeme: Hake alle ID-Lösungen an, über die deine Segmente adressierbar sind (z. B. Utiq).
  4. Kompatible DSPs: Wähle alle Plattformen aus, auf denen Einkäufer deine Daten nutzen können.
  5. Kompatible Curation-SSPs: Hake angebundene SSPs an, die Daten-Targeting / Curation unterstützen.
  6. Speichern & Veröffentlichen:
    • Klicke links unten auf Speichern / Übernehmen.
    • Klicke rechts auf den blauen Button Änderungen speichern & veröffentlichen.

B. Für Administratoren (Core Config)

  • Tabs: Über die Reiter DSPs, SSPs, ID-Systeme, Usecases und Data Partners wechselst du zwischen den Stufen.
  • Neuen Partner / Eintrag anlegen: Klicke auf + Neu erstellen und vergib eine technische ID (z. B. adform, pubmatic).
  • Verknüpfungen: Setze kompatible Partner in den Checkbox-Gruppen.
  • Speichern: Immer zuerst links Speichern / Übernehmen, danach rechts Änderungen speichern & veröffentlichen klicken.
